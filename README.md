# Portfólio Fotográfico — André Luiz Crispim

Landing page para portfólio fotográfico, com páginas de home, portfólio e contato.

## Estrutura do projeto

```
meu-site/
│
├── index.html          (Página 1 - Home)
├── portfolio.html       (Página 2 - Portfólio + Depoimentos)
├── contato.html         (Página 3 - Contato)
│
├── /imagens
│   ├── /portfolio
│   │   ├── casamentos/
│   │   ├── retratos/
│   │   └── eventos/
│   ├── /sobre
│   │   └── foto-perfil.jpg
│   └── /depoimentos
│
└── README.md
```

## Páginas e conteúdo

- **index.html** — Home: header, hero, prévia do portfólio, sobre (resumido), CTA final, footer
- **portfolio.html** — Galeria completa por categoria de trabalho + depoimentos
- **contato.html** — Formulário de contato

## Tecnologias usadas

- HTML5

## Como visualizar o projeto

Abrir o arquivo `index.html` diretamente no navegador.
